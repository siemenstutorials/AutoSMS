## 为什么选择 AutoSMS？

### 面向全球业务，按国家与服务选择号码

跨境电商、国际化应用和跨地区产品测试，往往需要不同国家的短信接收资源。AutoSMS 将国家、服务和线路选择集中在一个工作台，帮助用户根据实际业务匹配号码，减少在多个服务入口之间反复切换的操作。

支持的国家、服务与线路以当前通道目录为准；不同服务可选择的地区可能不同。

### 10万+号码池资源，按需获取

AutoSMS 接入 **10万+号码池资源**，为不同地区与服务的验证码接收需求提供选择。用户可以查询当前项目、对比可用线路与积分价格，再按需获取号码。

号码池规模描述平台接入的资源规模，不代表任一国家、服务或线路始终有对应数量的可用号码；实时库存以工作台或 API 查询结果为准。

### 多通道选择，兼顾价格与接收需求

AutoSMS 提供多通道接码入口。用户可根据服务支持情况、国家、线路价格，以及界面提供的历史收码成功率等信息选择合适线路。当某一组合暂无库存或暂时受限时，可以查看其他可用国家、服务或通道。

历史成功率用于辅助选择，实际接收结果取决于具体服务、号码与当时的可用情况。

### 收到验证码才收费，成本更清晰

**普通用户取号不扣本站积分，成功收到并保存验证码后，才按任务价格扣费。没有成功保存可计费验证码，不扣本站积分。**

| 订单行为 | 普通用户本站积分计费 |
| --- | --- |
| 获取号码、等待验证码 | 不扣积分，也不预扣或冻结本次收码积分 |
| 成功接收并保存新的验证码 | 按任务创建时锁定的积分价格计费 |
| 重复查看或查询同一条已保存验证码 | 不重复扣费 |
| 多条接码模式 | 按每条新增且未重复的验证码计费，并非整单只扣一次 |

取号与收码时需保持足够的可用积分。这里的“收到验证码”指平台成功接收并保存验证码，不代表目标网站已经完成注册或验证；单条、多条模式以具体项目支持情况为准。

### 网页直接使用，也能接入自己的业务系统

日常操作可以通过网页完成；需要系统集成时，可使用 AutoSMS 的短信验证码接收 API，查询项目与线路、获取号码、查询验证码并管理接码任务。开发者无需分别接入各通道的上游接口。

## 开发者：短信验证码 API 接入

AutoSMS 提供基于 **HTTPS GET** 的 API，响应为 **UTF-8 JSON**，使用本站用户名 `name` 与 API 密钥 `ApiKey` 鉴权，参数名区分大小写。

推荐接入流程：

**查询账户 → 查询项目与可用线路 → 获取号码 → 查询验证码 → 按任务状态结束处理。**

下面是只读账户查询示例。先在本地设置 `AUTOSMS_USERNAME` 与 `AUTOSMS_API_KEY` 环境变量，再在 Bash / zsh 中执行：

```bash
curl --get 'https://www.autosms.org/out/ext_api/getUserInfo' \
  --data-urlencode "name=${AUTOSMS_USERNAME}" \
  --data-urlencode "ApiKey=${AUTOSMS_API_KEY}"
```

- API 密钥请在服务端管理，不要提交到公开仓库或放入浏览器前端代码。
- 国家、项目与线路标识应使用对应通道接口返回的原值，不能混用。
- 处理响应时同时检查 HTTP 状态与 JSON 业务码；取号结果不确定时，按文档的请求标识规则处理。
- 号码和验证码应按字符串处理，保留 `+` 与前导零；查询验证码应设置截止时间。

完整参数、返回码、计费与号码管理说明：[AutoSMS API 文档（需登录）](https://www.autosms.org/site_api_docs.php)。

## 常见问题

### AutoSMS 是什么平台？

AutoSMS 是面向全球业务的多通道在线接码与短信验证码接收平台。用户可以通过网页或 API，按当前支持的国家、服务与线路获取号码并接收验证码。

### AutoSMS 官网地址是什么？

官网为 **[https://www.autosms.org/](https://www.autosms.org/)**。账号注册、用户登录、接码工作台和 API 文档均从官网进入。

### 10万+号池是否代表每个国家都有大量库存？

10万+指平台接入的号码池资源规模。具体国家、服务与线路的可用号码会变化，请以工作台或 API 的实时查询结果为准。

### 获取号码就会扣费吗？

普通用户获取号码不扣本站积分；平台成功接收并保存新的可计费验证码后，才按任务锁定价格扣费。重复读取同一验证码不会重复扣费，多条模式按新增且未重复的验证码分别计费。

### 没收到验证码怎么办？

先查看订单状态与剩余时间，在有效收码窗口内等待。符合当前取消条件时，可按界面操作取消；也可以在结束当前任务后选择其他可用线路。没有成功保存可计费验证码，不扣普通用户本站积分。

### 如何查询 ChatGPT、Claude、Amazon 等服务的接码项目？

登录工作台后，按实际服务名称搜索目录，再查看支持的国家、通道、线路及积分。项目是否上架、是否有库存，以及目标服务是否接受该号码，以当时的目录与实际验证要求为准。

### 可以通过 API 自动取号和查询验证码吗？

可以。AutoSMS 提供项目查询、号码获取、验证码查询和任务管理接口。请先阅读[官方 API 文档](https://www.autosms.org/site_api_docs.php)，按对应通道规则处理标识、请求状态与收码截止时间。

### 页面取消、API 停止收码与退款是一回事吗？

这些操作的处理范围不同。网页订单按当前界面条件执行取消；API 停止收码不等于上游退号或退款。请以官方文档的操作说明为准，避免把停止查询当作退款凭证。

### 充值支持什么网络？

充值使用 **USDT-TRC20**。请按订单显示的收款地址和应付金额转账，链上确认后自动到账；订单状态可在充值中心查看。

### 遇到问题如何联系 AutoSMS？

访问 [AutoSMS 官网](https://www.autosms.org/)，通过在线客服或登录后的联系管理员入口咨询。涉及订单时，提供对应任务编号或订单编号，便于定位。

## AutoSMS — Global SMS Verification & Multi-Channel SMS API

**A 100,000+ number pool. Multiple channels. Pay when a verification code is received.**

AutoSMS is an online SMS verification platform for individuals, international business teams and developers. It brings country, service and route selection into a web workspace, with an SMS API for integration into applications and internal workflows.

### Key benefits

- **Built for global workflows:** choose from the countries and services currently supported in the catalog.
- **100,000+ number-pool resources:** access a broad pool of numbers; live availability varies by country, service and route.
- **Multi-channel selection:** compare available options using listed prices and, where available, historical SMS delivery statistics.
- **Pay on successful SMS receipt:** standard user accounts spend site credits when a new billable verification code is successfully received and saved. Number allocation itself does not deduct or freeze those credits.
- **Web and API access:** receive codes in the dashboard or integrate number allocation and code retrieval through an HTTPS API.

Reading the same saved code again does not incur another charge. Supported multi-message projects charge for each new, non-duplicate code rather than once per order. Receiving a code does not guarantee that the destination service will complete registration or verification.

Create an account, top up site credits using USDT-TRC20, select an available country and service, obtain a number and request an SMS from the corresponding service. The verification code appears in your AutoSMS workspace when received.

For integrations, use your AutoSMS username (`name`) and API key (`ApiKey`). Consult the official documentation for channel-specific identifiers, request handling, response codes and billing rules.
